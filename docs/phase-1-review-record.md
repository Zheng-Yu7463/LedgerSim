## 执行边界

M1A 领域内核是唯一生产语义执行器：

```text
命令 -> decide -> 领域事件
事件 -> evolve -> 四层状态
事件 + 会计案例 -> 凭证
事件 + 因果边 + 账务差额 -> 标签
对象时间 + 观察策略 -> 可见性
祖先规范事件 -> shared_history_fingerprint
```

黄金测试调用领域内核，并将实际事件、逐步状态、凭证、标签和可见性与冻结夹具比较。
黄金夹具不能由领域内核自动覆盖；夹具变更必须单独评审并更新摘要。

M1A 暂不声明财务报表对象可见。收入、成本和利润只保留为派生错报指标；正式报表对象及其可见性等待 `PeriodClosed` 进入领域事件后实现。
